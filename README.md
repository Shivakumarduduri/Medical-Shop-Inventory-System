**# Medical Shop Inventory & Sales Analysis System**

Project Description
This project is used to manage medical shop data and analyze sales and inventory.

Features
- Best selling medicine identification
- Category-wise sales analysis
- Expiring medicines detection
- Dead stock identification
- Stock update functionality

Tables Used
- medicineInfo
- Customers
- Sales

 Key Queries
- Best selling medicine
- Expiring in 7 days
- Dead stock (not sold in 60 days)
- Category-wise sales

 Technologies Used
- SQL Server
